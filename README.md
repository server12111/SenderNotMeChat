# Sender Pro — Telegram-бот для рассылок по чатам

aiogram 3 (интерфейс) + Telethon (отправка с аккаунтов пользователей) + SQLAlchemy 2 async (SQLite / PostgreSQL) + APScheduler.

## Возможности
- **Рассылки:** постоянные, с циклами («КД между циклами» и «КД между чатами»), несколько вариантов сообщения (случайный выбор), спинтакс `{а|б}`, фото/видео, время активности, ротация аккаунтов.
- **Чаты:** @username, ссылки, ID, инвайты, файл .txt и **папки** `t.me/addlist/…` (папка добавляется на аккаунт сама). Вступление в чаты — с паузой и суточным лимитом.
- **Автоподписка на спонсоров:** если аккаунт тегнули и просят подписаться (кнопки или текст), он вступает и нажимает «Проверить».
- **Аккаунты:** вход по номеру (код кнопками, 2FA), `.session`, tdata, StringSession; свой API; SOCKS5-прокси (VIP); общий клиент на аккаунт.
- **Тарифы PRO / VIP:** создаются в админке; оплата по реквизитам (карта, USDT, BTC) с уникальной суммой и ручным подтверждением; промокоды; уведомления об окончании.
- **Админ-панель** (`/admin`, только `ADMIN_IDS`): тарифы, промокоды, реквизиты, заявки, дашборд, пользователи, сервисная рассылка, техобслуживание.

## Запуск
```
pip install -r requirements.txt
cp .env.example .env     # BOT_TOKEN, ADMIN_IDS, API_ID, API_HASH
python main.py
```
Дальше: `/admin` → Реквизиты (адрес и курс, включить способ) → Тарифы.

## Хостинг
Всё, что должно пережить перезапуск (база `bot.db`, ключ шифрования сессий `secret.key`, медиа), лежит в `DATA_DIR`
(по умолчанию `/app/data` на сервере, `./data` локально). Задайте `ENCRYPTION_KEY` в переменных окружения — так сессии
аккаунтов точно останутся читаемыми. Для PostgreSQL: `DATABASE_URL=postgresql+asyncpg://user:pass@host/db` + `pip install asyncpg`.

## Структура
- `bot/handlers` — start, accounts, mailings, billing (покупка), admin, admin_billing
- `bot/services` — sender (циклы рассылок), clients (пул Telethon), joiner (вступление, папки, спонсоры), billing, rates, plans, notifier
- `bot/middlewares` — access (регистрация, бан, техработы, тариф), guard (права перед запуском)
- `bot/database` — модели и подключение · `bot/keyboards` · `bot/utils`
